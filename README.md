Adonis Helper is a utility designed to simplify the installation and setup of **Adonis Admin** for your Roblox game.

### ✨ Installation

Installing Adonis through Adonis Helper ensures that your game receives the **latest available version of Adonis**, helping keep your admin system up to date with the latest improvements, fixes, and updates.

1. Run Adonis Helper.
2. Follow the installation instructions provided by the helper.
3. Allow the helper to install the latest available Adonis version.
4. Once installation is complete, verify that Adonis is running correctly in your game.

### 🔄 Keeping Adonis Updated

Adonis Helper is designed to make keeping Adonis up to date easier. When installing, it retrieves the latest available version rather than relying on an outdated local copy.

**Note:** Make sure to use Adonis Helper whenever you need to reinstall or update Adonis to ensure you're using the latest available release.
